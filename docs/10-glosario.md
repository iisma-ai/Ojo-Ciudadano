# 10 · Glosario

| Término | Significado |
| --- | --- |
| **Adjudicación** | Acto por el que el órgano de contratación elige la oferta ganadora. Importe adjudicado ≠ importe final. |
| **Formalización** | Firma del contrato tras la adjudicación. |
| **Liquidación** | Cierre económico del contrato: lo realmente pagado. |
| **Presupuesto base de licitación** | Importe máximo que el órgano está dispuesto a pagar; referencia para calcular la baja. |
| **Baja** | Diferencia entre presupuesto base y precio adjudicado. |
| **Baja anormal (temeraria)** | Oferta tan baja que hace dudar de que pueda cumplirse. |
| **Contrato menor** | Contrato de importe bajo que puede adjudicarse directamente: < 15.000 € (servicios y suministros) o < 40.000 € (obras), IVA excluido. |
| **Fraccionamiento** | Dividir un objeto contractual en varios contratos para quedar bajo umbrales y evitar licitar. Prohibido por la Ley 9/2017 de Contratos del Sector Público. |
| **Procedimiento abierto / restringido** | Procedimientos con publicidad y concurrencia (en el restringido solo ofertan los invitados tras una selección). |
| **Negociado sin publicidad** | Procedimiento excepcional en el que el órgano negocia sin anuncio público. |
| **Emergencia** | Tramitación excepcional sin procedimiento ordinario por causas de urgencia grave. |
| **Modificación** | Cambio en el contrato tras su formalización, a menudo con incremento de importe. |
| **Prórroga** | Extensión del plazo del contrato prevista en los pliegos. |
| **Pliegos** | Documentos que rigen la licitación (cláusulas administrativas y prescripciones técnicas). |
| **Mesa de contratación** | Órgano que valora las ofertas; sus actas recogen nº de ofertas y exclusiones. |
| **Órgano de contratación** | Entidad pública que contrata (consejería, organismo, empresa pública…). Identificado por código de órgano (DIR3). |
| **CPV** | *Common Procurement Vocabulary*: código europeo que clasifica el objeto del contrato. |
| **NIF / CIF** | Identificador fiscal. Las personas jurídicas empiezan por letra (A, B…); DNI/NIE corresponden a personas físicas. |
| **UTE** | Unión Temporal de Empresas: agrupación de varias empresas para un contrato, con NIF propio. |
| **HHI** | Índice Herfindahl-Hirschman: suma de los cuadrados de las cuotas de mercado; mide concentración. |
| **PLACSP** | Plataforma de Contratación del Sector Público (estatal). |
| **BDNS / SNPSAP** | Base de Datos Nacional de Subvenciones / Sistema Nacional de Publicidad de Subvenciones y Ayudas Públicas. |
| **RPT** | Relación de Puestos de Trabajo. |
| **OCDS** | *Open Contracting Data Standard*: estándar abierto de datos de contratación. |
| **Red flag** | Indicador de riesgo en contratación pública (terminología de la OCP). |
| **CKAN** | Software de catálogos de datos abiertos usado por la Comunidad de Madrid. |
| **Cámara de Cuentas** | Órgano de control externo de la Comunidad de Madrid. |
